# Review Section - React + Vite

A beautiful, infinite-scrolling testimonial section converted to React and Vite.

## Features
- Pixel-perfect conversion from HTML/CSS to React.
- Seamless infinite scrolling animation using CSS and React `useEffect`.
- Modern glassmorphism UI and glow effects.

## Running Locally

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```
